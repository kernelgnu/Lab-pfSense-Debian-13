# Lab pfSense-Debian-13

## Descrição do Projeto
Laboratório de segurança de redes utilizando pfSense como firewall e Debian 13 como sistema interno, implementado em ambiente virtualizado com VirtualBox. O projeto tem foco em estudo, documentação e validação de conceitos de firewall, roteamento e segurança de redes, com abordagem Blue Team.

## Objetivo
Criar um ambiente controlado para testes de segurança de redes, permitindo:
- Configuração e análise de firewall
- Monitoramento de tráfego
- Simulação de redes internas protegidas
- Base para futuras implementações de IDS/IPS, VPN e serviços de rede

## Ambiente Utilizado
- **Hypervisor:** VirtualBox
- **Firewall:** pfSense
- **Sistema Interno:** Debian 13
- **Modo de Rede:** Rede Interna + NAT
- **Modo Promíscuo:** Ativado em todas as interfaces
